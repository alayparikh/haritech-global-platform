# Team photos

Drop portrait photos here. They are picked up automatically — no code change.

## Naming

The file name is the person's name, lowercased, with every run of
non-alphanumeric characters replaced by a single hyphen:

| Person        | File name          |
| ------------- | ------------------ |
| `Tejas Patwa` | `tejas-patwa.jpg`  |

Accepted extensions, in the order they are preferred: `.webp`, `.jpg`, `.png`.

## Photo guidance

- **Portrait crop, 4:5** (e.g. 1200×1500). The frame crops to 4:5, so a
  landscape photo will lose the sides.
- Head and shoulders, eyes roughly a third down the frame.
- Even lighting, uncluttered background — a plant floor or plain wall both work.
- Aim for 1200px on the long edge; anything larger is wasted bytes.

## Until a photo is added

The person renders as a brand monogram plate with their initials, so the
section stays presentable with no photo and no broken image.
